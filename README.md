# Catálogo de Películas - Seminario Desarrollo Mobile UNICEN

Aplicacion Android desarrollada en Kotlin utilizando Jetpack Compose, MVVM, Hilt y Room para el consumo de la API de The Movie Database (TMDB).

## Configuracion para ejecutar el proyecto
1. Obtener una API Key en [The Movie Database (TMDB)](https://www.themoviedb.org/).
2. En la raiz del proyecto, crear o editar el archivo `local.properties`:
   ```properties
